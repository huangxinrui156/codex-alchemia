# 万物炼金手记 · Codex Alchemia

以四种原初元素为起点的触控合成解谜游戏。Vite、React 与 TypeScript 构建，所有图鉴、配方、合成判定和声音均在浏览器本地运行。

[进入炼金工作台](https://huangxinrui156.github.io/codex-alchemia/)

## 游戏内容

- 416 个元素、824 条无序配方、7 个分类、15 件终极奇观与 18 项成就。
- 点击抽屉投放元素，拖动铭牌相互重叠后松手合成。也可依次轻点两张铭牌。水与水合成湖泊，火与火合成烈焰。
- 长按或双击铭牌复制。双指轻点画布打开清空确认。上下滑动抽屉把手可折叠或展开。
- 图鉴可搜索名称或编号、查看分类收集进度、展开真实发现谱系，或查看未知词条的线索。
- 已发现元素、首次合成谱系、布局、成功次数和静音状态自动保存在当前浏览器。手记支持 JSON 文件或存档码导入导出。导入时验证配方、发现顺序和位置。
- 键盘可用 Tab 聚焦铭牌，Enter 依次选择两张进行合成，D 复制当前铭牌。声音在首次交互后由 Web Audio 合成。

## 本地运行

使用 Node.js 22.12+ 与 npm。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

构建命令先运行 Vitest，再运行严格的 TypeScript 检查，最后生成可独立托管的 `dist/`。

## 结构与实现

| 位置 | 职责 |
| --- | --- |
| `src/data/catalogue.txt` | 按分类维护中英文名称及输入对。每条配方占词条行中的一个字段 |
| `src/engine/graph.ts` | 构建无序输入索引，计算从四个根出发的最短合成层级和线索 |
| `src/engine/save.ts` | 合成状态更新、存档版本及校验、响应式桌面坐标 |
| `src/engine/graph.test.ts` | 独立可达性遍历、配方一致性、奇观深度、谱系与存档回归测试 |
| `src/engine/audio.ts`、`milestones.ts` | 纸张与风铃音效合成、成就进度计算 |
| `src/components/` | 工作台、博物图鉴、手记、可展开谱系、星图与 SVG 徽记 |
| `.github/workflows/deploy.yml` | 在 main 更新时测试、构建、上传并部署 Pages |

图谱用无序元素对查找结果，允许同元素自合成，每个非初始词条有两条路径。独立测试反复遍历所有配方直到发现集合稳定，再与完整目录比较。图鉴按照首次发现时的实际输入构建谱系，父节点始终早于子节点解锁。

工作台使用 Pointer Events 和指针捕获，移动超过 5 CSS 像素后开始拖动并取消长按。坐标以可用画布的比例保存，旋转屏幕后铭牌仍位于边界内。拖动预览按动画帧刷新，松手后提交布局或合成结果。重叠的最近候选会显示金色描边。

羊皮纸铭牌位于暗色星盘上层。四色原初元素与分类徽记用本地 SVG 绘制，图鉴编号、双语名称与铜版画线条沿用至抽屉和图鉴。静音与减少动态效果设置独立生效。

## GitHub Pages

仓库的 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。`main` 分支的推送会触发部署，也可在 Actions 手动运行。Vite 使用相对资源路径，支持仓库子路径。
